# 千里江山 Qianli Jiangshan

绢色为底、石青石绿为主、赭石打底的浅色主题，取自王希孟《千里江山图》（北宋），深色版为 qianli-jiangshan-night。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-qianli-jiangshan-theme
```
